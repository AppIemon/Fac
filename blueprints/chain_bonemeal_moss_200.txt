# 생산 계획: bone_meal  200개/시간
기준 버전: Minecraft 26.2 (Chaos Cubed)

## 필요한 공장 (하류 → 상류)

1. 이끼 뼛가루 팜 (퇴비통 포함 순수지)  [mossfarm_loop]
   유닛      : 3 베드  (이론값 2.82)
   시공 단위 : 총 3채 — 1베드 x 3채
   가동률    :  94.1%  (수요 200.0 / 능력 212.6 개/시간, 상시 가동)
   소비      : stone 2,430.0/h
   생산      : bone_meal 212.6/h
   근거      : [~] 뼛가루 1개 → 이끼 27개 + 초목 16개, 퇴비 환산 3.36개 (순 +2.36) · 회전 30회/시간 가정
   한계      : 이끼 수확이 수동이라 회전수가 산출을 좌우한다. 30회/시간은 가정값이다.
   한계      : 초목만 퇴비화하면 뼛가루 0.85개로 오히려 손해다. 이끼 블록(65%)을 반드시 같이 넣어야 순이익이 난다.
   한계      : 베드는 '돌'이어야 한다. 조약돌은 이끼로 변환되지 않는다.
   한계      : 퇴비통 뱅크가 함께 필요하다: litematic composterbank
   설계도    : python3 -m engine.cli litematic mossbed

2. 조약돌 → 돌 제련  [smelt_cobble_to_stone]
   유닛      : 7 화로  (이론값 6.75)
   가동률    :  96.4%  (수요 2,430.0 / 능력 2,520.0 개/시간, 수요 연동)
   소비      : coal 303.8/h, cobblestone 2,430.0/h
   생산      : stone 2,430.0/h
   근거      : [O] 화로 1대 = 아이템당 200틱 → 360개/시간 · 석탄 1개당 8개
   한계      : 호퍼 1줄로는 화로 25대까지. 그 이상은 원료 라인을 나눈다.
   설계도    : python3 -m engine.cli litematic smelter --furnaces 7

3. 조약돌 생성기  [cobblegen]
   유닛      : 2 생성칸  (이론값 1.01)
   가동률    :  50.6%  (수요 2,430.0 / 능력 4,800.0 개/시간, 상시 가동)
   생산      : cobblestone 4,800.0/h
   근거      : [~] 오버월드 용암 확산 30틱 → 칸당 이론상 2,400개/시간
   한계      : 바닐라에는 자동 블록 파괴기가 없다. 실제 산출은 플레이어의 곡괭이질(초당 1~2개 = 시간당 3,600~7,200개)로 막힌다 — 칸을 늘려도 이 상한을 못 넘는다.
   한계      : 물먹임 계단을 써야 용암 수원이 흑요석이 되지 않는다.
   설계도    : python3 -m engine.cli litematic cobblegen --cells 2

## 주의
  · 가동률이 낮은 공정은 그만큼 놀고 있다는 뜻이다. 목표 수량을 올리거나 유닛 수를 줄여 맞출 것.
  · 스폰 청크는 1.21.9에서 삭제됐다. 체인 전체가 한 플레이어의 AFK 범위 안이거나 /forceload 되어야 동시에 돈다.
