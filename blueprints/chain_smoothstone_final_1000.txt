# 생산 계획: smooth_stone  1,000개/시간
기준 버전: Minecraft 26.2 (Chaos Cubed)

## 필요한 공장 (하류 → 상류)

1. 돌 → 매끄러운 돌 제련  [smelt_stone_to_smooth]
   유닛      : 3 화로  (이론값 2.78)
   가동률    :  92.6%  (수요 1,000.0 / 능력 1,080.0 개/시간, 수요 연동)
   소비      : fuel_smelt 1,000.0/h, stone 1,000.0/h
   생산      : smooth_stone 1,000.0/h
   근거      : [O] 화로 1대 = 아이템당 200틱 → 360개/시간 · 석탄 1개당 8개
   한계      : 호퍼 1줄로는 화로 25대까지. 그 이상은 원료 라인을 나눈다.
   설계도    : python3 -m engine.cli litematic smelter --furnaces 3

2. 제자리 돌 생성기  [stonegen]
   유닛      : 1 생성칸  (이론값 0.42)
   가동률    :  41.7%  (수요 1,000.0 / 능력 2,400.0 개/시간, 상시 가동)
   생산      : stone 2,400.0/h
   근거      : [~] 용암이 위에서 물로 흘러들면 물이 '돌'이 된다 · 용암 확산 30틱 → 칸당 이론상 2,400개/시간
   한계      : 조약돌 경로는 두 번 구워야 하지만 이쪽은 한 번이면 된다 → 연료 절반.
   한계      : 채굴은 수동. 실제 상한은 곡괭이질(시간당 3,600~7,200개)이다.
   한계      : 이끼 베드에 넣을 돌도 여기서 나온다 (조약돌은 이끼로 변환 안 됨).
   설계도    : python3 -m engine.cli litematic stonegen --cells 1

3. 말린 켈프 블록 연소  [burn_dried_kelp_block]
   유닛      : 91 투입구  (이론값 90.91)
   가동률    :  99.9%  (수요 1,818.2 / 능력 1,820.0 개/시간, 수요 연동)
   소비      : dried_kelp_block 90.9/h
   생산      : fuel_smelt 1,818.2/h
   근거      : [O] 위키 확인: 말린 켈프 블록 4,000틱 = 20개 제련 (석탄 8개의 2.5배). 블록을 만드는 데 켈프 9개를 굽느라 9개분을 되먹으므로 순 11개분.
   한계      : 연료는 고리다. 켈프를 말리는 화로도 같은 연료를 먹는다.

4. 말린 켈프 → 블록 (제작기)  [craft_dried_kelp_block]
   유닛      : 1 대  (이론값 0.09)
   가동률    :   9.1%  (수요 90.9 / 능력 1,000.0 개/시간, 수요 연동)
   소비      : dried_kelp 818.2/h
   생산      : dried_kelp_block 90.9/h
   근거      : [~] 위키 확인: 말린 켈프 9개 → 블록 1개
   한계      : 제작기 자체 속도가 아니라 호퍼 급이(초당 2.5개)가 상한이다.

5. 켈프 → 말린 켈프 제련  [smelt_kelp_to_dried]
   유닛      : 3 화로  (이론값 2.27)
   가동률    :  75.8%  (수요 818.2 / 능력 1,080.0 개/시간, 수요 연동)
   소비      : fuel_smelt 818.2/h, kelp 818.2/h
   생산      : dried_kelp 818.2/h
   근거      : [O] 화로 1대 360개/시간
   설계도    : python3 -m engine.cli litematic smelter --furnaces 3

6. 켈프 팜  [kelp_farm]
   유닛      : 111 포기  (이론값 110.82)
   시공 단위 : 총 2채 — 64포기 x 1채, 47포기 x 1채
   가동률    :  99.8%  (수요 818.2 / 능력 819.5 개/시간, 상시 가동)
   생산      : kelp 819.5/h
   근거      : [~] 켈프 성장 14%/랜덤틱 → 평균 9,752틱 (488초) → 포기당 7.38개/시간
   한계      : 물기둥 안에서만 자란다. 관측기+피스톤으로 자란 칸을 끊는다.
   설계도    : python3 -m engine.cli litematic kelpfarm --columns 64

## 주의
  · 가동률이 낮은 공정은 그만큼 놀고 있다는 뜻이다. 목표 수량을 올리거나 유닛 수를 줄여 맞출 것.
