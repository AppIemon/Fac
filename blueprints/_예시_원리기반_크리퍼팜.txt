# 설계도: creeper 팜 (원리 기반 자동 설계)
기준 버전: Minecraft 26.2 (Chaos Cubed, 2026-06-16)
입력 원리: source=natural_spawn / transport=water / process=fall / collect=hopper
대상: creeper / 차원: overworld
선택된 아키타입: mob_platform_tower
확정 파라미터: {'platform': 15, 'layers': 5, 'spacing': 3, 'drop': 23, 'xp': False, 'mob': 'creeper'}

========================================================================
1. 작동 원리
========================================================================
어둠 속 자연 스폰 → 물길로 한 점 집결 → 낙하 데미지 처치 → 호퍼 수거

[설계 근거]
  - creeper 체력 20 → 낙하 데미지 공식(거리-3)으로 즉사시키려면 23블록 필요
  - 오버월드 자연 스폰은 '어두운 면적 확보 + 몹캡 독점'이 핵심 → mob_platform_tower

========================================================================
2. 규격
========================================================================
  가로(X) 15 x 높이(Y) 40 x 세로(Z) 15 블록
  배치 블록 수: 2,048개
  예상 산출: 스폰 가능 블록 1120칸 → 시간당 약 2,822마리 (추정)

5. 시공 순서
========================================================================
  1) 부지 확보: 15x15 평면 x 5층, 층 간격 3블록.
  2) 최하단부터 바닥 → 벽 순서로 쌓고, 각 층 중앙 1칸은 비워 낙하 통로로 연결.
  3) 각 층 물길 설치. 바깥 끝에서 중앙 구멍 방향으로 흐르게, 8칸마다 수원.
  4) 중앙 통로를 아래로 23블록 파고, 바닥에 호퍼 → 상자.
  5) 주변 32블록 내 모든 동굴/어두운 공간 밀봉 또는 조명 (몹캡 경쟁 제거).
  6) AFK 지점을 스폰층 위 24블록 이상, 수거부 128블록 이내에 설치.

========================================================================
6. 설계 메모
========================================================================
  * 수거부: Y=-24 (x=0, z=0) 호퍼 → Y=-25 큰 상자
  * 낙하 높이 23블록 → 데미지 20 (체력 20)
  * AFK 지점: 스폰 플랫폼 최상단에서 위로 24블록 이상 (Y≈38)

========================================================================
7. 경고 / 자주 실패하는 지점
========================================================================
  ! 스폰 플랫폼 내부 블록광은 반드시 0. 인근 동굴은 전부 밀봉하거나 조명 처리.
  ! 스폰 청크는 1.21.9에서 삭제됨 → AFK 상주 또는 /forceload 로 청크를 고정해야 팜이 돈다.

========================================================================
8. 시공 후 점검표
========================================================================
  [ ] 스폰 구역 블록광이 0인가? (횃불/용암/빛나는 블록 전부 제거)
  [ ] 주변 128블록 내 경쟁 스폰 지면을 차단했는가? (동굴 밀봉, 반 블록/광원)
  [ ] AFK 지점이 스폰 구역에서 24블록 이상, 수거부에서 128블록 이내인가?
  [ ] 아이템이 5분 안에 호퍼에 들어가는가? (안 그러면 소멸)
  [ ] 호퍼 처리량이 산출량보다 큰가? (호퍼 1개 = 초당 2.5개)
  [ ] 청크 로딩 대책이 있는가? 스폰 청크는 1.21.9에서 삭제됨 → AFK 또는 /forceload
  [ ] 몹이 물길 밖으로 새어나가는 틈이 없는가? (거미는 벽 등반, 엔더맨은 순간이동)
  [ ] 상자가 가득 찼을 때 팜이 멈추지 않게 오버플로 라인이 있는가?
