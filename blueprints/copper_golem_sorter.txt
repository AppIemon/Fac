# 설계도: 구리 골렘 자동 분류소 (26.x) (copper_golem_sorter)
기준 버전: Minecraft 26.2 (Chaos Cubed, 2026-06-16)
분류: 마을/골렘/습격 / 차원: overworld / 난이도: ★★
영문명: Copper Golem Sorter
아키타입: item_sorter
검증 상태: mechanics  (산화되면 동작 저하 → 밀랍칠 필요. 고속 팜에는 부적합)
참고 설계 계보(검색 키워드): (1.21.9 신규)
AFK 필요: 예

========================================================================
1. 작동 원리
========================================================================
구리 골렘이 구리 상자에서 최대 16스택 픽업 → 같은 아이템이 든 나무 상자에만 투입

========================================================================
2. 규격
========================================================================
  가로(X) 12 x 높이(Y) 2 x 세로(Z) 1 블록
  배치 블록 수: 21개
  예상 산출: 채널 10개, 라인 처리량 초당 2.5개 (병렬 시 x라인수)

========================================================================
3. 층별 평면도 (위에서 내려다본 뷰)
========================================================================
── Y=-1 층 ────────
    012345678901
  0 ..##########

── Y=+0 층 ────────
    012345678901
  0 C.cccccccccc

기호  블록
 #    건축 블록(아무 불투명 블록)
 C    큰 상자(더블)
 c    상자

========================================================================
4. 재료 목록
========================================================================
  상자                               10개
  건축 블록(아무 불투명 블록)                 10개
  큰 상자(더블)                          1개

========================================================================
5. 시공 순서
========================================================================
  1) 입력용 '구리 상자' 1개를 두고, 팜 산출물을 여기로 모은다.
  2) 골렘이 걸어다닐 통로를 따라 목표 '나무 상자'들을 배치한다.
  3) 각 나무 상자에 분류하려는 아이템을 미리 넣어둔다(같은 종류만 투입됨).
  4) 구리 골렘을 소환/배치한다. 산화되면 동작이 느려지므로 밀랍칠 권장.
  5) 상자가 가득 차면 골렘이 멈추니, 오버플로 라인을 별도로 둔다.

========================================================================
6. 설계 메모
========================================================================
  * 입력: 구리 상자 (골렘이 여기서 최대 16스택 픽업)
  * 각 목표 상자에 분류할 아이템을 미리 1개씩 넣어두면 그 아이템만 들어간다

========================================================================
7. 경고 / 자주 실패하는 지점
========================================================================
  ! 구리 골렘은 '아이템 종류/이름/인챈트'가 같은 상자에만 넣는다. 빈 상자는 아무거나 받으므로 반드시 지정 아이템을 미리 넣을 것.
  ! 레드스톤 분류기보다 느리다. 고속 팜에는 아래 클래식 호퍼 분류기를 쓸 것.
  ! 산화되면 동작 저하 → 밀랍칠 필요. 고속 팜에는 부적합

========================================================================
8. 시공 후 점검표
========================================================================
  [ ] 스폰 구역 블록광이 0인가? (횃불/용암/빛나는 블록 전부 제거)
  [ ] 주변 128블록 내 경쟁 스폰 지면을 차단했는가? (동굴 밀봉, 반 블록/광원)
  [ ] AFK 지점이 스폰 구역에서 24블록 이상, 수거부에서 128블록 이내인가?
  [ ] 아이템이 5분 안에 호퍼에 들어가는가? (안 그러면 소멸)
  [ ] 호퍼 처리량이 산출량보다 큰가? (호퍼 1개 = 초당 2.5개)
  [ ] 청크 로딩 대책이 있는가? 스폰 청크는 1.21.9에서 삭제됨 → AFK 또는 /forceload
  [ ] 몹이 물길 밖으로 새어나가는 틈이 없는가? (거미는 벽 등반, 엔더맨은 순간이동)
  [ ] 상자가 가득 찼을 때 팜이 멈추지 않게 오버플로 라인이 있는가?
