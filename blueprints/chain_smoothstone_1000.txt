# 생산 계획: smooth_stone  1,000개/시간
기준 버전: Minecraft 26.2 (Chaos Cubed)

## 필요한 공장 (하류 → 상류)

1. 돌 → 매끄러운 돌 제련  [smelt_stone_to_smooth]
   유닛      : 3 화로  (이론값 2.78)
   가동률    :  92.6%  (수요 1,000.0 / 능력 1,080.0 개/시간, 수요 연동)
   소비      : coal 125.0/h, stone 1,000.0/h
   생산      : smooth_stone 1,000.0/h
   근거      : [O] 화로 1대 = 아이템당 200틱 → 360개/시간 · 석탄 1개당 8개
   한계      : 호퍼 1줄로는 화로 25대까지. 그 이상은 원료 라인을 나눈다.
   설계도    : python3 -m engine.cli litematic smelter --furnaces 3

2. 조약돌 → 돌 제련  [smelt_cobble_to_stone]
   유닛      : 3 화로  (이론값 2.78)
   가동률    :  92.6%  (수요 1,000.0 / 능력 1,080.0 개/시간, 수요 연동)
   소비      : coal 125.0/h, cobblestone 1,000.0/h
   생산      : stone 1,000.0/h
   근거      : [O] 화로 1대 = 아이템당 200틱 → 360개/시간 · 석탄 1개당 8개
   한계      : 호퍼 1줄로는 화로 25대까지. 그 이상은 원료 라인을 나눈다.
   설계도    : python3 -m engine.cli litematic smelter --furnaces 3

3. 조약돌 생성기  [cobblegen]
   유닛      : 1 생성칸  (이론값 0.42)
   가동률    :  41.7%  (수요 1,000.0 / 능력 2,400.0 개/시간, 상시 가동)
   생산      : cobblestone 2,400.0/h
   근거      : [~] 오버월드 용암 확산 30틱 → 칸당 이론상 2,400개/시간
   한계      : 바닐라에는 자동 블록 파괴기가 없다. 실제 산출은 플레이어의 곡괭이질(초당 1~2개 = 시간당 3,600~7,200개)로 막힌다 — 칸을 늘려도 이 상한을 못 넘는다.
   한계      : 물먹임 계단을 써야 용암 수원이 흑요석이 되지 않는다.
   설계도    : python3 -m engine.cli litematic cobblegen --cells 1

## 직접 공급해야 하는 원료 (자동화 공정 미등록)
  coal                         250.0개/시간

## 남는 부산물
  cobblestone                  1,400.0개/시간

## 주의
  · 가동률이 낮은 공정은 그만큼 놀고 있다는 뜻이다. 목표 수량을 올리거나 유닛 수를 줄여 맞출 것.
  · 스폰 청크는 1.21.9에서 삭제됐다. 체인 전체가 한 플레이어의 AFK 범위 안이거나 /forceload 되어야 동시에 돈다.
