# 생산 계획: smooth_stone  1,000개/시간
기준 버전: Minecraft 26.2 (Chaos Cubed)

## 필요한 공장 (하류 → 상류)

1. 돌 → 매끄러운 돌 제련  [smelt_stone_to_smooth]
   유닛      : 3 화로  (이론값 2.78)
   가동률    :  92.6%  (수요 1,000.0 / 능력 1,080.0 개/시간, 수요 연동)
   소비      : fuel_smelt 1,000.0/h, stone 1,000.0/h
   생산      : smooth_stone 1,000.0/h
   근거      : [O] 화로 1대 = 아이템당 200틱 → 360개/시간 · 석탄 1개당 8개
   한계      : 호퍼 1줄로는 화로 25대까지. 그 이상은 원료 라인을 나눈다.
   설계도    : python3 -m engine.cli litematic smelter --furnaces 3

2. 조약돌 → 돌 제련  [smelt_cobble_to_stone]
   유닛      : 3 화로  (이론값 2.78)
   가동률    :  92.6%  (수요 1,000.0 / 능력 1,080.0 개/시간, 수요 연동)
   소비      : cobblestone 1,000.0/h, fuel_smelt 1,000.0/h
   생산      : stone 1,000.0/h
   근거      : [O] 화로 1대 = 아이템당 200틱 → 360개/시간 · 석탄 1개당 8개
   한계      : 호퍼 1줄로는 화로 25대까지. 그 이상은 원료 라인을 나눈다.
   설계도    : python3 -m engine.cli litematic smelter --furnaces 3

3. 조약돌 생성기  [cobblegen]
   유닛      : 1 생성칸  (이론값 0.42)
   가동률    :  41.7%  (수요 1,000.0 / 능력 2,400.0 개/시간, 상시 가동)
   생산      : cobblestone 2,400.0/h
   근거      : [~] 오버월드 용암 확산 30틱 → 칸당 이론상 2,400개/시간
   한계      : 바닐라에는 자동 블록 파괴기가 없다. 실제 산출은 플레이어의 곡괭이질(초당 1~2개 = 시간당 3,600~7,200개)로 막힌다 — 칸을 늘려도 이 상한을 못 넘는다.
   한계      : 물먹임 계단을 써야 용암 수원이 흑요석이 되지 않는다.
   설계도    : python3 -m engine.cli litematic cobblegen --cells 1

4. 말린 켈프 블록 연소  [burn_dried_kelp_block]
   유닛      : 182 투입구  (이론값 181.82)
   가동률    :  99.9%  (수요 3,636.4 / 능력 3,640.0 개/시간, 수요 연동)
   소비      : dried_kelp_block 181.8/h
   생산      : fuel_smelt 3,636.4/h
   근거      : [O] 위키 확인: 말린 켈프 블록 4,000틱 = 20개 제련 (석탄 8개의 2.5배). 블록을 만드는 데 켈프 9개를 굽느라 9개분을 되먹으므로 순 11개분.
   한계      : 연료는 고리다. 켈프를 말리는 화로도 같은 연료를 먹는다.

5. 말린 켈프 → 블록 (제작기)  [craft_dried_kelp_block]
   유닛      : 1 대  (이론값 0.18)
   가동률    :  18.2%  (수요 181.8 / 능력 1,000.0 개/시간, 수요 연동)
   소비      : dried_kelp 1,636.4/h
   생산      : dried_kelp_block 181.8/h
   근거      : [~] 위키 확인: 말린 켈프 9개 → 블록 1개
   한계      : 제작기 자체 속도가 아니라 호퍼 급이(초당 2.5개)가 상한이다.

6. 켈프 → 말린 켈프 제련  [smelt_kelp_to_dried]
   유닛      : 5 화로  (이론값 4.55)
   가동률    :  90.9%  (수요 1,636.4 / 능력 1,800.0 개/시간, 수요 연동)
   소비      : fuel_smelt 1,636.4/h, kelp 1,636.4/h
   생산      : dried_kelp 1,636.4/h
   근거      : [O] 화로 1대 360개/시간
   설계도    : python3 -m engine.cli litematic smelter --furnaces 5

7. 켈프 팜  [kelp_farm]
   유닛      : 222 포기  (이론값 221.64)
   시공 단위 : 총 4채 — 64포기 x 3채, 30포기 x 1채
   가동률    :  99.8%  (수요 1,636.4 / 능력 1,639.0 개/시간, 상시 가동)
   생산      : kelp 1,639.0/h
   근거      : [~] 켈프 성장 14%/랜덤틱 → 평균 9,752틱 (488초) → 포기당 7.38개/시간
   한계      : 물기둥 안에서만 자란다. 관측기+피스톤으로 자란 칸을 끊는다.
   설계도    : python3 -m engine.cli litematic kelpfarm --columns 64

## 주의
  · 가동률이 낮은 공정은 그만큼 놀고 있다는 뜻이다. 목표 수량을 올리거나 유닛 수를 줄여 맞출 것.
  · 스폰 청크는 1.21.9에서 삭제됐다. 체인 전체가 한 플레이어의 AFK 범위 안이거나 /forceload 되어야 동시에 돈다.
